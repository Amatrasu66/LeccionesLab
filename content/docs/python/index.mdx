## Collection Complexity Cheat Sheet

| Container | Operation | Average Complexity | Worst Case | Notes |
|---|---|---|---|---|
| **List** | Index lookup `l[i]` | $O(1)$ | $O(1)$ | Direct pointer offset |
| **List** | Append `l.append(x)` | $O(1)$ amortized | $O(N)$ | Infrequent dynamic array growth |
| **List** | Insert/Delete at index 0 | $O(N)$ | $O(N)$ | Must shift all subsequent pointers |
| **Tuple** | Index lookup `t[i]` | $O(1)$ | $O(1)$ | Fixed-length pointer array |
| **Dictionary** | Lookup `d[key]` | $O(1)$ | $O(N)$ | Hash table open addressing |
| **Dictionary** | Insert `d[key] = val` | $O(1)$ | $O(N)$ | Insertion-ordered compact hash table |
| **Set** | Membership `x in s` | $O(1)$ | $O(N)$ | Hash table membership verification |

## Upcoming Curriculum Tracks

The following advanced tracks are scheduled in subsequent content releases:

### Track C: Modules & Standard Library (Upcoming)
- Import machinery, `sys.path`, `__name__ == "__main__"`.
- Essential standard library modules: `pathlib`, `os`, `sys`, `json`, `csv`, `datetime`, `collections`, `itertools`, `subprocess`, `argparse`.
- Modern packaging with `pyproject.toml` and virtual environment management.

### Track D: Intermediate Language Features (Upcoming)
- First-class functions, closures, and lambda expressions.
- Iterators, the iterator protocol (`__iter__`, `__next__`), and generator functions (`yield`, `yield from`).
- Function and class decorators, parameterized decorators.
- Exception hierarchies, context managers (`with`, `contextlib`), and static typing with `mypy`/`pyright`.

### Track E: Object-Oriented Programming (Upcoming)
- Classes, instance vs. class attributes, static methods, and `@classmethod`.
- Inheritance, composition, polymorphism, and Method Resolution Order (`super()`, MRO).
- Dunder methods (`__repr__`, `__eq__`, `__add__`), descriptors, `@property`, and `__slots__`.
- Abstract Base Classes (`abc.ABC`), structural subtyping (`typing.Protocol`), and `dataclasses`.

### Track F: Advanced Python & Runtime Internals (Upcoming)
- CPython memory model, reference counting, and cyclic garbage collection (`gc` module).
- Concurrency models: multithreading (GIL constraints), multiprocessing, and `concurrent.futures`.
- Asynchronous programming with `asyncio`, coroutines, tasks, and asynchronous context managers.
- C extensions, ctypes, and performance profiling.

### Track G: Professional Engineering Practices (Upcoming)
- Testing with `pytest`, fixtures, parameterization, mocking, and coverage analysis.
- Code quality toolchains: `Ruff` linter/formatter, static type checking, pre-commit hooks.
- Architecture patterns, dependency injection, and secure coding practices.

### Track H: Backend Application Engineering (Upcoming)
- Asynchronous Web APIs with **FastAPI**: Pydantic validation, dependency injection, async route handlers.
- Production Web Services with **Django**: ORM, migrations, authentication, and security hardening.
- Relational databases, connection pooling with SQLAlchemy, and PostgreSQL migrations.

## Suggested Starting Pathway

1. If you are setting up your workstation, start with **[Getting Started](/docs/python/getting-started)**.
2. If you want to understand core syntax and data types, read **[Syntax & Primitive Data Types](/docs/python/basics/syntax-and-types)**.
3. If you want to master Python's memory model, read **[Variables & Assignment](/docs/python/basics/variables)**.
4. For collection performance and algorithms, dive into **[Lists & Dynamic Arrays](/docs/python/collections/lists)** and **[Dictionaries & Hash Tables](/docs/python/collections/dictionaries)**.
