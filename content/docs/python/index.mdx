## Execution Model

In Python, every variable is a symbolic reference to a heap-allocated object. Unlike compiled languages with rigid stack memory slots, Python binds names dynamically:

```python
# Variables bind to heap-allocated objects
values = [10, 20, 30]
alias = values  # 'alias' references the exact same list object in memory
alias.append(40)

print(values)  # -> [10, 20, 30, 40]
print(values is alias)  # -> True (identical memory address)
```
